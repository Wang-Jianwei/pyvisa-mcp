# Raw Layer

This directory stores append-oriented project inputs and durable research captures.

Rules:
- Keep source-oriented notes here.
- Prefer dated note names under `raw/notes/`.
- Do not turn raw notes into polished wiki summaries.
- Add new notes or dated corrections instead of silently rewriting history.

Recommended subdirectories:
- `notes/` for distilled research notes and decision baselines.
- `external/` for imported source copies when needed.
- `assets/` for downloaded images and binary attachments.
- `sources/` for inventories and manifests when needed.
